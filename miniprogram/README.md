# Loongson AOI 微信小程序

这是 AOI 网站的微信小程序移动端。新版小程序与手机浏览器访问下面两个地址保持同一套业务语义：

```text
http://172.25.208.1:8020/
http://172.25.208.1:8020/phone
```

小程序默认连接运行完整网站的后端 `http://172.25.208.1:8020`，不再绕过网站直接只调用云端 8010。这样小程序、`/phone` 页面和完整网站共享同一个上传队列、检测平台选择、缺陷结果和 LLM 诊断报告。

## 当前模式

- 模拟模式：小程序可导入模拟图片到网站后端；完整网格扫描和拼接复核建议在完整网站继续操作。
- 真实模式：龙芯端网站负责滑台、OV9281、soft home 和拍照；小程序只查看状态与入口，避免误触运动机构。
- 手机拍照：小程序可拍照或从图库选择图片，上传到网站手机队列，并按选择的平台执行整图检测。

## 检测平台

小程序顶部与网站一致，提供三个检测平台：

- 华为云：网站后端调用 ECS/OBS 云端检测。
- 手机：需要另有手机浏览器推理 worker 在线。
- 本地电脑/龙芯：运行网站后端的设备使用 OpenCV DNN 本地检测。

检测失败时不会自动切换平台，需要手动选择其他平台后重新运行。

## 配置地址

编辑 `app.js`：

```js
App({
  globalData: {
    consoleApiBase: "http://172.25.208.1:8020",
    cloudApiBase: "http://1.92.113.191:8010",
    cloudWsBase: "ws://1.92.113.191:8010"
  }
});
```

主要使用的是 `consoleApiBase`。`cloudApiBase/cloudWsBase` 保留作调试信息和后续直连云端备用。

## 开发者工具验证

1. 在电脑或龙芯端启动完整网站：

   ```powershell
   cd D:\AAAED\code\Loongson_AOI_PCB\worktrees\cloud-cooperative-platform
   python -m uvicorn main:app --host 0.0.0.0 --port 8020
   ```

2. 用浏览器确认：

   ```text
   http://172.25.208.1:8020/health
   http://172.25.208.1:8020/
   http://172.25.208.1:8020/phone
   ```

3. 用微信开发者工具导入 `worktrees/cloud-cooperative-platform/miniprogram`。

4. 开发阶段勾选“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”。

5. 在小程序中：

   - 刷新系统状态。
   - 选择“手机拍照”模式。
   - 选择检测平台。
   - 拍照或图库选图。
   - 上传到手机队列。
   - 点击“开始整图检测”。
   - 查看标注图、最终缺陷账本和 LLM 诊断报告。

## 真机限制

微信正式真机发布要求 HTTPS/WSS 合法域名。`http://172.25.208.1:8020` 适合局域网调试和开发者工具验证；正式演示建议给 8020 配 HTTPS 域名或通过 APIG/Nginx 反向代理暴露。
