# Loongson AOI 微信小程序

这是 Loongson AOI 网站的微信小程序端，功能和手机浏览器访问下面两个页面保持同一套业务语义：

```text
http://116.205.117.33:8020/
http://116.205.117.33:8020/phone
```

小程序默认连接完整网站后端 `http://116.205.117.33:8020`，共享同一套上传队列、检测平台选择、缺陷结果、标注图和 LLM 诊断报告。

## 当前功能

- 支持三种运行模式：模拟模式、真实模式、手机拍照。
- 支持三类检测平台：华为云、手机、本地电脑/龙芯。
- 支持拍照或从图库选图，并上传到网站的手机图片队列。
- 支持选择上传图片后执行整图检测。
- 支持查看原图、标注图、缺陷账本、推理耗时和报告状态。
- 支持对手机整图结果生成 LLM 诊断报告。
- 支持在页面内临时修改网站后端地址，便于在不同局域网切换。

## 运行模式说明

- 模拟模式：小程序可把图片导入网站后端；完整模拟扫描和拼接建议在完整网站界面继续操作。
- 真实模式：龙芯端网站负责滑台、OV9281、soft home、拍照和检测，小程序只作为状态入口，避免误触发真实机械运动。
- 手机拍照：小程序拍照或选图上传到网站队列，再按所选平台执行整图检测。

## 检测平台说明

- 华为云：网站后端调用 ECS/OBS 云端检测链路。
- 手机：需要另有手机浏览器推理 worker 在线；小程序本身不内置 ONNX 浏览器 worker。
- 本地电脑/龙芯：由运行网站后端的设备通过 OpenCV DNN 执行本地检测。

检测失败时不会自动切换平台，需要手动选择其他平台后重新运行。

## 地址配置

默认地址在 `app.js` 中配置：

```js
App({
  globalData: {
    consoleApiBase: "http://116.205.117.33:8020",
    cloudApiBase: "http://116.205.117.33:8010",
    cloudWsBase: "ws://116.205.117.33:8010"
  }
});
```

日常调试主要修改 `consoleApiBase`。小程序首页也提供了临时地址输入框，便于现场快速切换到龙芯板或 Windows 本机网站。

## 微信开发者工具导入

1. 启动完整网站，例如：

   ```powershell
   cd D:\AAAED\code\Loongson_AOI_PCB\worktrees\cloud-cooperative-platform
   python -m uvicorn main:app --host 0.0.0.0 --port 8020
   ```

2. 在浏览器确认网站可用：

   ```text
   http://116.205.117.33:8020/health
   http://116.205.117.33:8020/
   http://116.205.117.33:8020/phone
   ```

3. 用微信开发者工具导入本目录：

   ```text
   D:\AAAED\code\Loongson_AOI_PCB\miniprogram
   ```

4. 开发阶段建议勾选：

   ```text
   不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书
   ```

5. 典型验证流程：

   - 刷新系统状态。
   - 选择“手机拍照”模式。
   - 选择检测平台。
   - 拍照或从图库选图。
   - 上传到手机队列。
   - 选择上传记录。
   - 点击“开始整图检测”。
   - 查看标注图、最终缺陷账本和 LLM 诊断报告。

## 真机限制

微信正式真机发布要求 HTTPS/WSS 合法域名。`http://116.205.117.33:8020` 适合局域网调试和开发者工具验证；正式演示建议给 `8020` 配 HTTPS 域名，或通过 APIG/Nginx 反向代理暴露。
