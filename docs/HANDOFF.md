# 队友接手指南

## 1. 接手顺序

1. 克隆私有仓库并切换到 `main`。
2. 执行 `pwsh -File .\tools\test_all.ps1`，确认软件基线。
3. 执行 `pwsh -File .\tools\verify_packages.ps1`，确认三个部署包与 SHA256。
4. 根据目标平台阅读对应部署文档。
5. 软件验收使用 motor dry-run；只有在现场确认原点和接线后才启用真实滑台。

## 2. 当前事实

- 产品只公开真实、手机拍照两种操作模式；内部模拟能力仅供测试和兼容。
- 两种模式均显示“本地（龙芯）→ 手机 → 华为云”三个实验档位，默认本地（龙芯），实际推理统一由华为云执行。
- 手机拍照按实验档位保留模拟链路延时；真实模式三个档位均为零延时。
- 网站入口为 `/`，手机上传页为 `/phone`，健康检查为 `/health`。
- 华为云检测服务默认端口 `8010`，完整网站默认端口 `8020`，龙芯现场默认端口 `8000`。
- 真实模式采集 16 张 1280×800 灰度图；检测依据是逐格结果，拼接大图不再次推理。
- 拼接采用固定物理几何与重叠羽化，不执行 PCB 边界识别或自动裁板。
- 龙芯 GPIO 由系统 Python 3.7 的 libgpiod v1 helper 执行，网站运行于 Python 3.12。
- 电机是开环控制，`position_trusted=false` 后必须人工确认原点并软回零。

## 3. 源码边界

- 网站主源码：`worktrees/cloud-cooperative-platform`。
- 云检测后端：根目录 `cloud-backend`。
- 小程序可直接导入根目录 `miniprogram`；网站目录内保留同步镜像供测试使用。
- 模型及训练代码：`worktrees/algorithm-ai`。
- 旧分支仅供查历史，不要再从旧分支复制文件覆盖 main。

## 4. 私有配置

`config/private` 中配置仅用于本私有仓库团队。轮换 LLM 或 OBS 密钥后，应同时更新该目录和目标服务器配置，并重新生成三个部署包。禁止把 GitHub PAT 或 SSH 私钥加入仓库。

## 5. 交接验收

- Windows dry-run 下真实模式和手机拍照模式均能选择三个实验档位，且结果记录 `experiment_profile` 与实际华为云平台。
- `/api/system/status` 能报告云、本机和手机 Worker 状态。
- 手机上传后电脑刷新队列能选择最新图，并支持最多 9 张批量检测。
- 龙芯真实模式必须先通过独立蛇形运动测试，再进行相机和检测联调。
- AI 报告应能选择模型、切换思考、导出 Markdown，并在工作台继续聊天。
