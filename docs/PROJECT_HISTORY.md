# 项目演进记录

## v1.0.0 之前的主要阶段

1. **基础 AOI**：完成 YOLOv8 七类 PCB 缺陷训练、评估和单图检测。
2. **龙芯兼容**：把 PyTorch 权重导出为 FP32 ONNX，以 OpenCV DNN + NumPy 替代板端 Ultralytics。
3. **网站整合**：形成模拟、真实和手机拍照三种模式，通过 WebSocket 展示扫描状态。
4. **端云协同**：加入华为云 ECS、OBS、异步任务、小程序和浏览器 Worker。
5. **真实扫描**：接入 OV9281、TB6600、4×4 蛇形点位、速度与停稳时间控制。
6. **拼接与融合**：由特征估计和自动裁板转为物理视野固定几何；取消 PCB 边界识别，恢复固定坐标重叠羽化，缺陷以逐格检测为准。
7. **手机批处理**：加入最多 9 张上传、引用批次、顺序检测、精确删除和标注图导出。
8. **LLM 诊断**：加入多模型、思考开关、Markdown 报告、可调整三列工作台、SSE 聊天和多缺陷/多图上下文。
9. **电机兼容与保护**：采用 Python 3.12 网站 + 系统 Python 3.7 GPIO helper，增加匀速脉冲、遥测和开环位置可信保护。
10. **主线交接**：在 v1.0.0 将分散 worktree、部署包、测试夹具和文档统一到私有 `main`。

旧分支记录了阶段性实现，但可能包含过时模式、旧模型尺寸和旧拼接算法。遇到冲突时以 main 的测试、README 和部署包为准。
