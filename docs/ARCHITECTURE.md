# 系统架构

## 数据流

```text
浏览器 / 微信小程序
        |
        v
完整网站 FastAPI :8020 或龙芯 :8000
  |       |                    |
  |       |                    +-- 相机与滑台控制
  |       +-- 本机 OpenCV DNN
  +-- 华为云检测 API :8010 -- OBS
        |
        +-- 标注图、JSON、批次状态

最终检测结果 + 标注图 --> Qwen 视觉模型 --> 报告与连续聊天
```

## 真实模式

真实扫描使用固定 4×4 蛇形点位。第一点先拍照，随后依次移动和采集；16 张采集完成后即可回原点，拼接和结果整理不阻塞归位。每张照片单独检测并保存，最终账本由逐格结果融合。

扫描几何默认采用 X 轴 30mm、Y 轴 18mm、相机长边视野 39mm。图片按当前设备方向水平镜像后放置，重叠区域使用固定坐标羽化融合。系统不识别 PCB 外轮廓，不生成自动裁板结果。

## 检测路由

- `huawei_cloud`：上传云后端并轮询结果。
- `phone_browser`：由已连接浏览器 Worker 推理。
- `local_dnn`：运行网站的主机使用 OpenCV DNN。

手机拍照模式的三个实验档位统一使用华为云模型，以控制模型与后处理一致；模拟手机和模拟本地只附加实验链路延时，结果元数据保留实际执行平台。

## 持久化

扫描、手机上传、标注图、JSON 和 LLM 会话默认写入算法输出目录。运行数据不进入 Git。批次和扫描均使用安全 ID，不接受浏览器提交任意磁盘路径。
